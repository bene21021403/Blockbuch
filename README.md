# Blockbuch

Minecraft-Bedrock-Builds und Farmen in 3D mit Schichtansicht. Reines HTML/CSS/JS ohne Build-Schritt, gehostet über GitHub Pages.

## Lokal ausgelieferte Dateien (keine Anfragen an fremde Server)
- `vendor/three/three.min.js` – Three.js r128 (npm `three@0.128.0`, MIT)
- `assets/fonts/` – Pixelify Sans 500/700 und Atkinson Hyperlegible 400/700, nur latin und latin-ext (npm `@fontsource/*@5.3.0`, SIL OFL 1.1), eingebunden über `assets/fonts/fonts.css`

Lizenzen sind in der App unter `#lizenzen` verlinkt.
